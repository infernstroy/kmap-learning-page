1. Boolean basics and truth tables

A Boolean expression combines variables (0 or 1) using AND (AB), OR (A+B) and NOT (A′). A truth table lists the output for every input combination, so n inputs give 2n rows.

Useful laws: A+AB = A, AB+AB′ = A, A+A′ = 1, A·A′ = 0, De Morgan: (AB)′ = A′+B′, (A+B)′ = A′B′.

NOT depends only on A. NAND and NOR are universal gates: any circuit can be built from either one. XOR is 1 when the inputs differ; XNOR is 1 when they match.

3. SOP and POS

A minterm is an AND of all variables where each appears once (complemented if the input bit is 0). For ABC = 101 the minterm is AB′C = m5. A maxterm is an OR of all variables, complemented if the input bit is 1. For ABC = 101 it is A′+B+C′ = M5.

SOP (Sum of Products): OR together the minterms where F = 1. Example: F = AB + A′C.

POS (Product of Sums): AND together the maxterms where F = 0. Example: F = (A+B)(A′+C).

On a K-map, group the 1s for SOP, or group the 0s for POS (then read each group as a sum of the variables that stay constant, complemented as needed).

4. Karnaugh maps

A K-map is a grid version of the truth table arranged so that neighbouring cells differ by exactly one variable. Grouping neighbours removes the variable that changes, which simplifies the expression without algebra. A 4-variable map has 16 cells.

Grouping rules

  • Gray-code order: label rows and columns 00, 01, 11, 10 (never 00, 01, 10, 11).
  • Powers of two: groups contain 1, 2, 4, 8 or 16 cells. Sizes like 3 or 6 are not allowed.
  • Rectangles only: groups are rectangles of adjacent cells, no diagonals.
  • Wrap-around: the left and right edges are adjacent, and so are the top and bottom edges. The four corners form one group.
  • Go big: use the largest groups possible. Groups may overlap. Cover every 1 at least once.
  • Group size vs variables removed: a group of 2 removes 1 variable, a group of 4 removes 2, a group of 8 removes 3.
  • Don’t-cares (X): include them in a group only if it makes the group bigger.

5. Worked example

Simplify F(A,B,C,D) = Σm(0, 1, 2, 5, 8, 9, 10). Rows are AB, columns are CD.

Group P: the four corners m0, m2, m8, m10 (wrap-around both ways). B and D stay 0, so B′D′.
Group Q: m0, m1, m8, m9 (top row and bottom row wrap). B and C stay 0, so B′C′.
Group R: m1 and m5 (pair). A, C stay 0 and D stays 1, so A′C′D.

Result (SOP): F = B′D′ + B′C′ + A′C′D
Check m5 (A=0,B=1,C=0,D=1): A′C′D = 1·1·1 = 1, so F = 1. ✓
